OPTIONAL ADD-ON

Flash Station

Run kiosk mode on your own tablet, or later add a hardware package with a tablet, stand and light. Guests take one selfie per turn. They can optionally enter a mobile number to get it by text, then the station clears for the next person. The event owner chooses one look ahead of time, so there are no guest menus.

  • One photo per turn keeps the line moving
  • One event-wide look — no filter selection at the kiosk
  • Optional mobile number for immediate selfie delivery
  • Text the album link later to opted-in guests
  • Fast automatic reset gets the next guest on camera
